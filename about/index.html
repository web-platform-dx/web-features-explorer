About the web features explorer website

The goal of the Web platform features explorer website is to visualize the data that's in the web-features and web-features-mappings repositories.

This is a project from the W3C WebDX Community Group (WebDX CG). The source code is available on the web-features-explorer GitHub repo.

On this site, you'll find information about features of the web platform, such as their names, descriptions, which browsers they're supported on, their Baseline statuses, links to MDN documentation, specifications, vendor positions, vendor bugs, web platform tests, user surveys, browser usage counters, and more.

Other pages

Here are a few other pages that might be useful. These pages are not in the top-level navigation menu because they are either work-in-progress or experiments.

  • bcd-mapping: the list of unmapped BCD keys, and % of completion.
  • browse: a directory of the features, organized by web development tasks.
  • groups: a directory of the features, organized by web-feature groups.
  • ids: the list of all features, with their IDs, and BCD keys, to help find existing features.
  • statistics: trends for web-features coverage of BCD keys and caniuse IDs.
  • timeline: experimental timeline showing the number of baseline features over time.
