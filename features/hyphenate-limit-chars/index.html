Hyphenate limit chars

Limited availability

The hyphenate-limit-chars CSS property sets the number of characters in a word before it is hyphenated and the minimum number of characters on either side of the hyphen.

Browser support

  • Chrome 109 Released on 2023-01-10
  • Chrome Android 109 Released on 2023-01-10
  • Edge 109 Released on 2023-01-12
  • Firefox 137 Released on 2025-04-01
  • Firefox for Android 137 Released on 2025-04-01
  • Safari Not supported
  • Safari on iOS Not supported

Baseline availability blocked since April 2025 by Safari (16 months)
