background-size

Widely Available (since 2018-01-29)

The background-size CSS property scales or stretches a background based on the size of the element (with the contain and cover keywords), a length, or percentage.

Browser support

  • Chrome 21 Released on 2012-07-31
  • Chrome Android 25 Released on 2013-02-27
  • Edge 12 Released on 2015-07-29
  • Firefox 9 Released on 2011-12-20
  • Firefox for Android 18 Released on 2013-01-08
