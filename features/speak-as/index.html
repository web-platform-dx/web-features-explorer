speak-as

Limited availability

The speak-as CSS property sets how any element's content is spoken. Not to be confused with the speak-as descriptor of @counter-style at-rules.

Browser support

  • Chrome Not supported
  • Chrome Android Not supported
  • Edge Not supported
  • Firefox Not supported Bugs: 1748068
  • Firefox for Android Not supported Bugs: 1748068
