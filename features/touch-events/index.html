Touch events

Limited availability

Touch events touchstart, touchmove, touchend, and touchcancel fire when users interact with a touch-sensitive surface, such as a screen or drawing tablet. These events are similar to mouse events.

Browser support (view on caniuse.com)

  • Chrome 22 Released on 2012-09-25
  • Chrome Android 25 Released on 2013-02-27
  • Edge 12 Released on 2015-07-29
  • Firefox 52 Released on 2017-03-07
  • Firefox for Android 6 Released on 2011-08-16
  • Safari Not supported
  • Safari on iOS ≤3 Released before 2009-06-17

Baseline availability blocked since March 2017 by Safari (113 months)
