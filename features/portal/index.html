Portals

This feature is discouraged — The <portal> element was removed from browsers in favor of other proposals.

Consider using <fencedframe> , <link rel="prefetch"> , Speculation rules , View transitions instead.

For more information, see: WICG/portals/blob/421e74f5bb3e12d6d439ad19654a1463a5cb9b0a/README.md?plain=1#L1 (GitHub)

The <portal> HTML element embeds another page into the current page as a non-interactive preview.
