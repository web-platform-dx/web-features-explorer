Container style queries

Newly Available (since 2026-05-19)
Expected to be Widely Available on 2028-11-19

Container style queries with the @container at-rule apply styles to an element based on the values of custom properties of its container.

Browser support (view on caniuse.com)

  • Chrome 111 Released on 2023-03-07
  • Chrome Android 111 Released on 2023-03-07
  • Edge 111 Released on 2023-03-13
  • Firefox 151 Released on 2026-05-19
  • Firefox for Android 151 Released on 2026-05-19
  • Safari 18 Released on 2024-09-16
  • Safari on iOS 18 Released on 2024-09-16

MDN documentation

  • Container style queries, in `@container` CSS at-rule

Specifications

  • CSS Conditional Rules Module Level 5 (#style-container), from Cascading Style Sheets (CSS) Working Group (W3C).
