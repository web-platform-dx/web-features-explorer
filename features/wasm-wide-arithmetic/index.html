Wide arithmetic (WebAssembly)

Limited availability

Wide 128-bit integer arithmetic instructions operate on larger-than-64-bit numbers with results represented by two 64-bit integers. You can use these instructions to improve performance for some use cases, such as arbitrary precision math.
