showPicker() for <input>

Limited availability

The showPicker() method for <input> elements shows the user interface for picking a value. For example, for <input type="date"> it shows the interface for picking a date.

Browser support

  • Chrome 99 Released on 2022-03-01
  • Chrome Android 99 Released on 2022-03-01
  • Edge 99 Released on 2022-03-03
  • Firefox 101 Released on 2022-05-31
  • Firefox for Android 101 Released on 2022-05-31
  • Safari 17.4 Released on 2024-03-05
  • Safari on iOS Not supported Bugs: 261703

Baseline availability blocked since March 2024 by Safari (29 months)
