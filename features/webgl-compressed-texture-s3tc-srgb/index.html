WEBGL_compressed_texture_s3tc_srgb WebGL extension

Limited availability

The WEBGL_compressed_texture_s3tc_srgb extension for WebGL 1.0 and 2.0 contexts adds S3TC compressed texture formats for the sRGB colorspace to compressedTexImage2D() and compressedTexSubImage2D().

Browser support

  • Chrome 60 Released on 2017-07-25
  • Chrome Android 60 Released on 2017-08-01
  • Edge 80 Released on 2020-02-07
  • Firefox 55 Released on 2017-08-08
  • Firefox for Android Not supported
  • Safari 14.1 Released on 2021-04-26
  • Safari on iOS 14.5 Released on 2021-04-26

Baseline availability blocked since April 2021 by Firefox (64 months)
