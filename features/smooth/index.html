image-rendering: smooth

The image-rendering: smooth CSS declaration scales images while retaining a gradual color blending that is useful for photos.

Status

Limited availability

MDN documentation

  • `image-rendering` CSS property

Specifications

  • CSS Images Module Level 3 (#the-image-rendering), from Cascading Style Sheets (CSS) Working Group (W3C).
