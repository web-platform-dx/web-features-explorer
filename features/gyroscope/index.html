Gyroscope

Limited availability

This feature has received a negative standards position from at least one browser vendor — It's very unlikely to ever become Baseline in this current form.

The Gyroscope API reads the angular velocity of a device in three dimensions.

Browser support

  • Chrome 67 Released on 2018-05-29
  • Chrome Android 67 Released on 2018-05-31
  • Edge 79 Released on 2020-01-15
  • Firefox Not supported
  • Firefox for Android Not supported
  • Safari Not supported Position: oppose (concerns: duplication, privacy, venue, use cases, power, device independence)
  • Safari on iOS Not supported Position: oppose (concerns: duplication, privacy, venue, use cases, power, device independence)
