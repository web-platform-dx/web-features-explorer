ime-mode

This feature is discouraged — You should not modify the state of input method editor. Instead, you should use hints (such as a lang or inputmode attribute) to help the browser select the right user interface for text input.

Consider using inputmode , lang instead.

For more information, see: css-ui-3/#input-method-editor (CSSWG draft)

The ime-mode CSS property sets the state of the input method editor for text fields.
