New features in Chrome Android 158 (released on 2026-11-17)

  • flow-start and flow-end

    Limited availability

    The flow-start and flow-end CSS alignment values (as in justify-items: flow-start or align-self: flow-end) align items to the stacking axis (in grid lanes layouts) or the flex direction (in flexbox layouts), where placement begins and ends. In other contexts, the values behave as start and end.

  • OfflineAudioContext incremental rendering

    Limited availability

    The startRendering() method of the OfflineAudioContext API accepts an optional chunk size argument, which sets the number of sample frames to render in an AudioBuffer. You can use this to process audio incrementally, reducing the memory required to process high amounts of data.
